# Version 1.1.0 — July 2026

## Expanded

- Expanded the response examples from **6 to 12**, covering a broader range of real-world communication scenarios.
- Broadened guidance for healthcare, workplace, caregiving, and financial hardship conversations.

## Added

- Safety guidance for conversations involving possible self-harm or immediate risk.
- Explanatory notes following each example describing how the response aligns with HCOS™ 302 principles.
- New examples addressing:
  - Financial hardship
  - Anger
  - Shame after mistakes
  - Caregiver exhaustion
  - Immediate safety concerns
  - Responses that unintentionally increase burden
- Expanded communication style guidance emphasizing warm, genuine, human-centered language.

## Improved

- Stronger emphasis on recognizing system influences while preserving personal agency.
- Clearer distinction between compassion, accountability, and responsibility.
- Refined language to further reduce shame while preserving dignity.
- Improved consistency across the Standard, Prompt, and Examples documents.
- Clarified that examples illustrate principles rather than provide scripted responses.

## Documentation

- Added version metadata to supporting documents.
- Improved document organization for consistency with the HCOS Communication Series.
- Updated supporting documentation to align with the HCOS repository structure and release process.

# Version 1.0.0 — July 2026

## Initial Release

Published the initial release of **HCOS™ 302 – Compassionate Human-Centered Response**.

Included:

- Compassionate Human-Centered Response Standard
- Operational AI Prompt
- Initial set of six communication examples
- README documentation

Established the foundational HCOS principles of:

- Preserving human dignity
- Separating worth from circumstances
- Recognizing system influences
- Leading with compassion before solutions
- Preserving personal agency
- Reducing unnecessary shame through human-centered communication
